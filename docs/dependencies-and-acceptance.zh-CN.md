# 使用前需要准备什么

**装好两个插件和 Python 服务后，可以先体验工作台；完整业务闭环还需要自己的资料、模型账号和相应外部软件。** 官方桌面和本机 Web 都遵循这一点。

## 外部软件

按实际用途选择，不需要为了体验界面一次装齐。以下仅提供官网入口；具体版本和接入方式应与所用 ORION 版本配合验证。

| 软件 | 主要用途 | 官方入口 |
| --- | --- | --- |
| Protégé / HermiT | 本体建设与校验 | [Protégé 官网](https://protege.stanford.edu/) |
| Semantica | 图谱、规则校验与相关能力 | [Semantica 官方文档](https://docs.getsemantica.ai/) |
| Chat2DB | 数据库来源接入与选择 | [Chat2DB 官网](https://chat2db.ai/) |
| Docker / Ontop | 数据库映射、运行与查询 | [Docker 官网](https://www.docker.com/)、[Ontop 官网](https://ontop-vkg.org/) |
| PostgreSQL | 工作流与正式版本记录 | [PostgreSQL 官网](https://www.postgresql.org/) |
| Fuseki / MinIO | 资料图检索与原件存储 | [Apache Jena 官网](https://jena.apache.org/)、[MinIO 官网](https://www.min.io/) |
| PaddleOCR | 扫描件、图片文字识别 | [PaddleOCR 官网](https://www.paddleocr.ai/) |
| Wren | 可选的数据分析能力 | [Wren 官网](https://getwren.ai/) |

这些外部服务没有全部包含在交付包里，部分接入仍需实施配置。下载客户端或安装 Python 依赖，不代表已经完成连接和业务验收；上游任意最新版也不自动等于本项目已验证兼容。

## 选择使用范围

- **先体验界面**：按安装教程准备 Harness、两个插件和 Python 服务，查看工程模板、本体中心和外观设置。首次没有自己的本体和正式问答结果是正常的。
- **资料工程**：准备授权资料及相应解析能力；正式资料发布还需要存储和检索服务。
- **数据库工程**：准备授权数据源、只读账号及映射查询环境。
- **联合工程**：同时准备两条链，并核对资料与数据之间的关联。

正式建设与校验还需要可用的 Protégé、Semantica 等相应环境。所有模式都使用自己的模型账号、操作人和业务资料；当前完整远程多人服务器模式尚未交付。

## 怎样确认真正跑通

1. **来源真实可用**：自己的资料能正确解析，数据库在授权范围内可只读查询。
2. **工程有实际结果**：完成来源与语义审阅、人工设计批准、构建和质量校验，保存真实执行回执。
3. **发布经过批准**：对明确版本完成正式批准、部署和结果回读。
4. **问答能追溯证据**：用真实业务问题核对答案，能追溯到对应的发布版本、来源和资料。

建议先选一个小范围业务场景，由业务负责人给出预期答案，再逐项验收。**界面出现、端口可用或测试通过，都不能单独代表业务闭环。** 缺软件、未配置或未执行的部分，应如实标明，不能保证下载安装后就能跑通所有场景。

安装步骤见 [桌面教程](install.zh-CN.md) 或 [Web 教程](web-install.zh-CN.md)；需要 AI 协助时使用 [部署任务说明](ai-deployment.zh-CN.md)。
